# Inter-Node Link Management

The Inter-node Link Management option appears when you hover over the connection line between two nodes on the canvas. It allows users to **add a new node, unlink the connection, or add a branch** between connected nodes. Users can also **link two nodes** by dragging a connection from one node to another, creating a flow between them.![inter-node link options](/img/platform/key-concepts/workflow/inter-node-link-management/link-options.jpeg)

## 1. **Add a new node**  
   If a user wants to add a new node between two connected nodes, they can select “Add a Node”, which opens the app selection screen to choose and insert the node they want at that point in the workflow.  ![inter-node add a new node](/img/platform/key-concepts/workflow/inter-node-link-management/add-new-node.jpeg)![inter-node after adding a new node](/img/platform/key-concepts/workflow/inter-node-link-management/after-adding-new-node.jpeg)

## 2. **Add new branch**  
   If a user wants to add a branch for a new node, they can select “Add a Branch”, which opens a selection screen to choose a node for the new branch.![inter-node add a new branch](/img/platform/key-concepts/workflow/inter-node-link-management/add-new-branch.jpeg)![inter-node after adding a new branch](/img/platform/key-concepts/workflow/inter-node-link-management/after-adding-new-branch.jpeg)

## 3. **Unlink**  
   If a user wants to remove the connection between two nodes, they can select “Unlink” to disconnect the nodes and break the existing link between them.  ![inter-node unlink option](/img/platform/key-concepts/workflow/inter-node-link-management/unlink-option.jpeg)![inter-node unlink](/img/platform/key-concepts/workflow/inter-node-link-management/unlink.jpeg)
     
     
## 4. **Link**  
   If a user wants to connect two nodes, they can drag a connection from one node and attach it to another node, creating a new link between them. ![inter-node relink](/img/platform/key-concepts/workflow/inter-node-link-management/relink.jpeg)![inter-node relink how to](/img/platform/key-concepts/workflow/inter-node-link-management/relink-how-to.jpeg)
