# AGENTS.md

## Tech Stack
- Next.js 16+
- Tailwind CSS
- fumadocs (https://www.fumadocs.dev/)
- [fumadocs LLMs](https://www.fumadocs.dev/docs/integrations/llms)

## Dev Environment Instructions
- Clone the repository `git clone https://github.com/appseconnect/appse-ai-docs.git`
- Run `pnpm install` to install the dependencies
- Run `pnpm dev` to start the development server
- Open the browser and navigate to `http://localhost:3000`

## PR Instructions
- Create a new branch `git checkout -b feature/new-feature`
- Make the changes and commit them `git commit -m "Add new feature"`
- Build the project `pnpm build` for build verification before creating a PR
- Create a PR to the `main` branch
